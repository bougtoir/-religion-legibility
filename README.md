# Religion Legibility — Reproducibility Repository

Reproducibility code and derived analytical artifacts for:

**When Religion Becomes Countable: Normative Authority and Observability in Comparative Research**

This public repository intentionally excludes the submission manuscript, cover letter, private audit logs, and externally licensed raw data.

## Repository layout

```
analysis/          analysis and figure/table generation scripts
coding/            measurement-affordance and legibility coding files
data/
  raw/             acquisition ledger only; download raw datasets yourself
  processed/       derived analytical CSV/JSON outputs
tables/            curated/generated table CSVs
docs/              analysis decisions and methodological documentation
requirements.txt
```

## Raw data

Raw source datasets are not mirrored here where licensing or provider terms make public redistribution inappropriate. See:

`data/raw/ACQUISITION_LEDGER.json`

Place downloaded files at these exact paths:

- `data/raw/drh/drh_tables/answerset.csv`
- `data/raw/polaris/build_polaris_dataset/Polaris2026.xlsx`
- `data/raw/seshat/equinox/seshatdb-Equinox_Data-ed8f570/Equinox_on_GitHub_June9_2022.xlsx`

## Full analytical reproduction

Run from the repository root:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt

python analysis/seshat_missingness.py
python analysis/drh_missingness.py
python analysis/legibility_model.py
python analysis/canonical_results.py
python analysis/make_figures.py
python analysis/make_tables.py
```

The first three analysis steps require the external raw files above.
`canonical_results.py` depends only on processed outputs and coding files.
Processed outputs are not required to be stored publicly. After the three raw-data analysis steps run, canonical_results.py regenerates the canonical registry and the remaining scripts regenerate figures and tables.

## Canonical numerical registry

`data/processed/canonical_results.json` is the machine-readable registry for analysis-derived manuscript numbers. It is generated by:

`analysis/canonical_results.py`

## Important methodological note

Cross-collection Seshat values labelled `unknown` are treated as explicit epistemic-state coding conditional on recorded rows; absent rows are not automatically treated as missing observations. See:

- `docs/ANALYSIS_DECISIONS.md`
- `docs/ANALYSIS_PLAN.md`

The legibility-feature analysis is exploratory and rule-based, not preregistered or prospectively prespecified.
